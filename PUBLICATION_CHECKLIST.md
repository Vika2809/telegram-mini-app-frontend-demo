# Public release checklist

- [ ] Confirm written client/employer permission to publish source code and derivative designs.
- [ ] Review domain-specific business logic and API request/response structures for confidentiality.
- [ ] Verify the placeholder artwork is acceptable; do not restore proprietary assets.
- [ ] Confirm all production tokens, endpoints, wallets, account IDs and tracking IDs are absent.
- [ ] Run `npm ci`, `npm run build`, and relevant tests in a trusted environment.
- [ ] Verify the public repo has no private Git history or previous commits with secrets.
- [ ] Add a license only when authorized.
- [ ] Verify any screenshots shared on Upwork contain no real user/client data.
